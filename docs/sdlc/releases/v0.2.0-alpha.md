# Release v0.2.0-alpha: checklist

> **Status:** Prepared (2026-10-21), not released. **Owner:** project lead (release manager). **Prepared by:** A08 agent session.
> **Related:** [release process](../../engineering/release-process.md) · [roadmap §6](../../planning/roadmap.md#6-release-and-version-mapping) · [A08 phase review](../reviews/A08-phase-review.md) · [benchmark report](../../research-paper/benchmark-report-a08.md)

`v0.2.0-alpha` is the A08 milestone release: `v0.1.0-alpha` (A07) plus the ECHOMETRIC harness v0 and the replication gallery (roadmap §6). This file is the release checklist of the [release process](../../engineering/release-process.md#release-checklist) with the A08 evidence filled in. Tagging and publishing are the owner's; nothing here publishes anything.

## Order and mechanism

1. **`v0.1.0-alpha` first.** A07-T08 is not released yet, and its first publish of each crate is manual ([first release: owner steps](../../engineering/release-process.md#first-release-owner-steps)). `v0.2.0-alpha` follows it.
2. **The release PR comes from release-plz.** Once the owner has set up the GitHub App (first-release step 4), every push to `main` updates a release PR titled `chore(release): vX.Y.Z` that bumps every crate in one version group, writes the changelog, and reports cargo-semver-checks. Merging that PR publishes to crates.io, tags and creates the GitHub release. For that reason this phase does **not** open a hand-made version-bump PR. One with auto-merge on could publish without the owner's go, and one opened before `v0.1.0-alpha` would skip that release. The owner overrides the proposed version to `0.2.0-alpha` in the release PR if release-plz proposes another.
3. **In the release PR**, run `cargo xtask citation --release <YYYY-MM-DD>` (CITATION.cff and .zenodo.json; CI fails until it is done).
4. **New for this release:** `sonarithm-echometric` is now published with the CLI, which depends on it for `sonarithm study` (#179), so the first publish of `v0.2.0-alpha` includes one crate that `v0.1.0-alpha` did not. The owner publishes it once by hand and adds its crates.io trusted publisher, as for the other crates.
