## Decisions

| Decision | Why | Record |
|---|---|---|
| The draft `RenderGraph` contract has two halves: a `!Send` control half and an RT processor | Firewheel's context is `!Send` and its `update` is not real-time safe; it matches 06 §2 | F-036; gate report, ADR-0004 recommendation |
| Spikes live in `spikes/` with their own Cargo and pnpm roots; temporary workflows run only on changes under `spikes/` and are not required checks | Keep the workspace and required CI untouched | No ADR needed: throwaway, deleted after the gate |
| A02 findings use F-030 to F-049 | A03 appends findings in parallel from F-019 | Note in the findings log |
| CPU-limited reruns pin to 4 E-cores (`start /affinity F0000`) | A non-invasive stand-in for the 4-core reference laptop under the 12 §8 headroom rule; no system settings are changed | Benchmarks log, HW-01e |
| No system settings were changed for measurements (audio enhancements, GPU preferences) | Settings changes are the owner's call; the APO effect was measured with the RAW stream option instead | Owner steps P7 and P3 in the gate report |

## Problems and how they were solved

| Problem | Cause | Resolution |
|---|---|---|
| Loopback onsets missing and 110 ms paths | An OEM APO adds about 200 ms tails and 20 dB of gain, so the detector did not re-arm between cues | Trial interval raised to 400–700 ms; RAW mode added to separate the APO cost (F-032) |
| A 200-trial run lost its device | The headphones were unplugged during the run | Devices are now resolved per mode and stream errors counted; the run was repeated on the speakers |
| Speaker-to-microphone check failed | The microphone array's echo cancellation removes the rendered cue | Owner step P6 (USB interface or loopback cable) |
| Binary IPC returned JSON arrays | The CSP lacked `connect-src ipc: http://ipc.localhost` | CSP fixed; F-042 |
| Miri reported UB in the Firewheel test | std's Windows `System` allocator path under a custom global allocator | Reproduced without Firewheel (below); F-037 |
| Miri could not find sources after a branch switch | Miri reads sources at run time | Miri runs moved to exported copies of the branch |

### Miri reproduction (F-037)

`cargo +nightly miri run` (nightly 1.101.0, 2026-10-17) reports Stacked Borrows UB at `library/std/src/sys/alloc/windows.rs:189`, and Tree Borrows UB at line 199 with `-Zmiri-tree-borrows`. With `--target x86_64-unknown-linux-gnu` it prints `done`.

```rust
use std::alloc::{GlobalAlloc, Layout, System};

struct PassThrough;

unsafe impl GlobalAlloc for PassThrough {
    unsafe fn alloc(&self, layout: Layout) -> *mut u8 {
        unsafe { System.alloc(layout) }
    }
    unsafe fn dealloc(&self, ptr: *mut u8, layout: Layout) {
        unsafe { System.dealloc(ptr, layout) }
    }
}

#[global_allocator]
static ALLOC: PassThrough = PassThrough;

#[repr(align(128))]
struct Padded([u8; 512]);

fn main() {
    let b = Box::new(Padded([0; 512]));
    drop(b);
    println!("done");
}
```
