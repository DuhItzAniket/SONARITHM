## Context and phase

## Goals

- The CodeMirror 6 spec editor with live diagnostics, reachable and announced (T-12), keyboard-accessible completion from the generated JSON Schema, and an edit in the editor shown in the inspector and the reverse.

## What was done

- `@sonarithm/ui/code-editor` (`CodeEditor`) and `@sonarithm/ui/diagnostic-list` (`DiagnosticList`), each with stories, keyboard play tests and axe in four themes.
- `apps/desktop/src/spec/`: the spec store, the Spec tab, the Diagnostics panel, the editor's commands, JSON pointer placement and schema completion; unit tests in `apps/desktop/test/spec-pointer.test.ts` and six E2E tests in `apps/desktop/e2e/spec.spec.ts`.
- Seven commands in the `editor` and global scopes, `edit.undo` and `edit.redo` handlers, and the macOS Option-letter chord fix.

## Decisions

| Decision | Why | Record |
|---|---|---|
| No new IPC; one UI spec store fed by every reply that carries the spec | The app core has no spec-changed event; all spec edits in the UI go through the store | Coordinator go, 2026-11-26; 09 §3 as built |
| Completion opens only on request (Primary+I), never while typing, unless `editor.autoComplete` is on | A popup that opens while typing interrupts speech; Ctrl+Space breaks KB-04 | Coordinator, INFER, OD-30 walkthrough list; 12 §3 |
| Two undo histories, said apart | Primary+Z in the editor is text undo until there is none left; then, and outside, it is the spec history | Coordinator; keyboard §5.9 |
| CodeMirror and GridList load on demand | Start-up bundle (PB-07) | 09 §3 as built |
| CSP: the page's style nonce for CodeMirror's `<style>` element | Never `'unsafe-inline'` | F-229 |

## Problems and how they were solved

| Problem | Cause | Resolution |
|---|---|---|
| In WebKit, Tab from the tab list sometimes dropped the focus to the page | React Aria's tab panel keeps `tabindex="0"` a moment after lazy content appears (F-228) | The E2E waits for the panel to settle; open question for HP-07 |
| WebKit skipped the editor in the Tab order | WebKit leaves a contenteditable without a tabindex out of sequential navigation | `tabindex="0"` on CodeMirror's content element |
| Shift+Alt+F never fired on macOS | Option turns F into "Ï", and letters bind by character | An Alt chord keeps the letter key it was pressed on (`chordOf`, test) |
| The GridList landed in the start-up bundle | The `@sonarithm/ui` barrel put it in a chunk shared with the lazy panel | `DiagnosticList` is its own entry point |
| E2E runs hit another worktree's app | Playwright reuses whatever Vite runs on port 1430 | Local runs used port 1431 from a scratch config |
| Review of #505 (2026-11-28): typing during an Apply's compile lost its undo and kept a stale check; "Load the current spec" dropped the focus and the edits; an inspector patch replaced the draft's check; a failed check said "Checking" forever; Apply with no change added a history entry; a command waited forever for an editor that failed to load; columns counted UTF-16 units | Each a gap in the first design | Text history resets when `spec_set` succeeds; the draft is checked again whenever the latest check is of another text; the load is an undoable edit with the focus in the editor; a failed check is said and retried at the next change; `spec_set` skips identical text (Rust test); "The spec editor is not available"; columns count code points. Unit and E2E tests for each |
