# 2026-11-01: B03-T10, the braille review line and sparkline (Rust side)

> **Date(s):** 2026-11-01. **Phase:** B03. **Author:** project lead, written by an AI agent (Claude Code), reviewed by @DuhItzAniket.
> **Related:** [worklog conventions](README.md) · keyboard-and-navigation §10, §14 · [ADR-0017](../../decisions/0017-ipc-protocol-v1.md) "Braille"

## Context and phase

- B03-T10, Rust side; Lane U builds the field and the keys. The design was approved by the coordinator on 2026-11-01: Rust only, a pure AUDAXIS module, no fitting without a user-set cell count, and never a cut number.
- It was stacked on B03-T09's IPC (#447) and rebased onto main after #447 merged.

## What was done

- **AUDAXIS `braille`:**
  - `review_line` fits whole fields to the cell count and marks fields it leaves out with "…".
  - `sparkline` draws MAIDR's four heights (dots 78, 36, 25, 14; notes 03 §1), a blank cell for a missing value, and a window around the cursor.
  - `route` maps a cell to its point.
  - `Composer::review_fields` gives the cursor's parts in symbol form, unjoined.
- **App core:**
  - `CursorState.braille` (a `BrailleState`) goes with every cursor event when braille is on.
  - `braille_route` maps a routing-key press to a point; the new origin `CursorOrigin::Braille` is not announced, the same rule as the table (INFER, OD-30).
  - `settings.braille { mode, cells }`, with `cells: 0` refused.
- **Docs:** ADR-0017 "Braille" (with the `selectionchange` note from Lane U), keyboard §10 "as built", OD-30 extended, and a 05 §4 sentence on context-only providers (from CURVASONA's review of #434).

## Decisions

| Decision | Why | Record |
|---|---|---|
| No fitting without a cell count | A web page cannot read the display's cell count; MAIDR makes it a setting | keyboard §10, `settings.braille.cells` |
| Never cut a field | A shortened number misreports the value | `braille::review_line` |
| Cell count in app settings, not the profile | It belongs to the user's device; a profile field would change ADR-0020's format | coordinator, 2026-11-01 |
| A routing-key move is not announced | The display and the screen reader already show the field | INFER, OD-30 |
