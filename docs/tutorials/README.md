# Tutorials

Step-by-step lessons for people new to SONARITHM ([Diátaxis](../README.md#documentation-conventions): learning-oriented). Each step is one action and shows the text you should see, so the tutorials work with a screen reader.

| Tutorial | You will | Time |
|---|---|---|
| [Quickstart](quickstart.md) | Install SONARITHM, turn a CSV file into a FLAC file, and read in text what you hear | About 5 minutes |
