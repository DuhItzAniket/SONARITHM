# Datasets and stimulus generators

> **Status:** Baseline v1 (2026-10-18). **Owner:** Research lead.
> **Related:** [evaluation plan](evaluation-plan.md) · [experiments](experiments/README.md) · [hypotheses](hypotheses.md) · [benchmarks log](benchmarks-log.md) · [roadmap](../planning/roadmap.md) (A07, A08, C01–C05) · [ADR-0013](../decisions/0013-determinism-and-provenance.md)

This registry lists every dataset and stimulus generator that SONARITHM's examples, tests, benchmarks and studies use. An item gets an ID when it is planned and keeps it for life. A study or paper may use only registered items.

## Policy

- **Licences.** Datasets and stimuli created by the project: CC BY 4.0, as the research report suggests for example datasets and stimuli. Generator code: MIT OR Apache-2.0, like the rest of the codebase.
- **Provenance.** Each item records its source, its generator version and seed (if synthetic), and a stable data fingerprint. Rendered stimuli carry a render manifest (engine version, spec hash, data fingerprint, seed, sample rate, block size).
- **Synthetic first.** Examples and test corpora are generated from known data wherever possible. That keeps licences clean, gives exact ground truth and contains no personal data.
- **External data.** No external dataset is redistributed or used in a paper until its licence has been verified and recorded here. The kickoff research did not verify licences for the public sources listed below.
- **Personal data.** Registered datasets contain none. Participant data from studies is governed by each protocol's data-management section, not by this file.

Status vocabulary: `planned` → `available` (committed or archived, with fingerprint) → `retired`.

**Implementation (A08).** GEN-001 to GEN-004 live in `sonarithm_echometric::harness::generators`, one module each; the module documentation lists every published parameter with its page next to SONARITHM's choice and marks what the paper does not state. A stimulus carries its ground truth, notes on every departure from the published design, a canonical CSV and its SHA-256, and a manifest (generator ID and version, seed, parameters, digest). Pinned manifests are checked on Windows, macOS and Linux in CI. Generator version 1 is the A08 baseline; any change that alters the bytes for the same parameters and seed raises the version.

**Licence and ethics for all generators:** code MIT OR Apache-2.0; generated stimuli CC BY 4.0; no personal data. Generator versions are recorded in every stimulus manifest, so a study can be re-rendered exactly.

## Ethics notes

- **Bring-your-own data.** Co-design and usage sessions let participants use their own data, because engagement drops with uninteresting data (Chart Reader). Such data stays on the participant's machine where possible, is not retained after the session unless the participant explicitly agrees, and is never published.
- **Screenshots and chart images** can contain personal data. Cloud extraction is never used on participant material ([notes/06 §7](../research/notes/06-chart-extraction-ai.md)).
- **Hearing safety.** Generators and stimulus specs cap output level; studies state calibrated playback levels.
- **Representation.** Example datasets avoid stereotyped or sensitive topics and contain no data about identifiable people.
