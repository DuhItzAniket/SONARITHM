# Diagnostic code registry

> **Generated** by `cargo xtask codes` from the code tables in the crates; do not edit this file. To add or retire a code, change the table in the owning crate and run `cargo xtask codegen`.
> **Related:** [coding-standards §4.2](../engineering/coding-standards.md#42-diagnostic-codes) · [12 §1](../architecture/12-cross-cutting-concerns.md#1-error-handling-and-diagnostics) · [05 §7](../architecture/05-compiler-and-score-ir.md#7-diagnostics)

Every diagnostic carries a stable code `SNR-<AREA>-<NNN>`. A code, once released, is never reused or renumbered; retired codes stay listed. Severity is the default; settings such as `--deny-warnings` can raise it.
